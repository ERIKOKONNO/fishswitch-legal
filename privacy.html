魚スイッチ プライバシーポリシー

制定日: 2026年6月4日 / 最終更新日: 2026年9月19日

魚スイッチは、釣りの予定づくりと釣行記録をサポートするアプリです。 ユーザーの釣行記録やお気に入り地点は、原則として端末内に保存されます。

1. 取得する情報

本アプリでは、機能提供のために以下の情報を利用する場合があります。

  • お気に入り地点、選択中の釣り場、釣行記録、魚図鑑の表示状態など、ユーザーがアプリ内で保存した情報
  • 見守り機能を利用した場合の共有日、地点、帰宅予定時刻、終了報告の日時
  • 「匿名の釣果統計に協力」がオン（初期設定）の場合の、釣果記録から作成する集計用の情報（釣り場、月、3時間単位の時間帯、釣れた魚種、または釣れなかったこと）
  • 潮汐・天気・周辺施設を表示するための地点情報
  • 通知機能を利用する場合の通知許可状態、通知スケジュール
  • プレミアム機能を利用する場合の購入状態、購読状態、匿名のユーザー識別子
  • アプリの改善のために取得する、利用状況（画面の表示、機能の利用回数など）と匿名の識別子
  • アカウントでログインする場合の、ログイン方法（Apple または Google）に紐づく識別子、メールアドレス、ニックネームなどのプロフィール情報
  • 広告の配信、表示回数の計測、不正利用の防止に必要な、IPアドレスから推定されるおおまかな地域、端末情報、広告識別子、広告の表示・操作情報、診断情報

2. 情報の保存場所

釣行記録、お気に入り地点、見守り記録、プロフィール情報、通知設定などは、主にユーザーの端末内に保存されます。 見守り記録は、共有日から7日間を目安に端末内へ保持され、その後の新しい共有時に古い記録から整理されます。 ユーザーがバックアップ機能を利用した場合、記録データはユーザー自身が選択した場所にファイルとして保存されます。

アカウントでログインしてデータの同期を利用する場合、および釣果写真のクラウドバックアップを利用する場合は、 対象のデータが Google の提供する Firebase（Cloud Firestore / Cloud Storage）のサーバーに保存されます。 ログインせずにご利用の場合、これらのサーバーに釣行記録やお気に入り地点が保存されることはありません。

アプリ内の「匿名の釣果統計に協力」がオンの場合、釣果記録（この設定がオンになる前に記録したものを含みます）のうち、 釣り場、月、3時間単位の時間帯、釣れた魚種（釣れなかった場合はそのこと）だけを Firebase（Cloud Functions / Cloud Firestore）へ送信し、 他のユーザーの記録と合算した件数として保存します。写真、メモ、サイズ、正確な日時、端末の位置情報、名前は送信しません。 アカウントでログインしていない場合も、送信のために Firebase Authentication で匿名の識別子を発行します。 この識別子はアカウントとしては扱わず、ログインや同期には使いません。 集計データには送信者の識別子を含めず、同じ集計への重複加算を防ぐための不可逆な値だけを別に保持します。 この設定は初期状態でオンになっており、記録タブの設定からいつでもオフにできます。オフにすると以後の送信を停止し、まだ送信していない情報は端末から削除されます。

集計結果は、プレミアム機能「みんなの釣果から」で釣り場や周辺エリアごとの傾向として表示します。 記録が少ない場合は、釣り場より広いエリアや季節単位にまとめて表示し、送信者が分かる形で表示することはありません。 ご自身の記録は、ご自身の画面の集計には含めません。

3. 外部サービスの利用

本アプリでは、以下の外部サービスを利用する場合があります。

  • 潮汐データ取得: tide736.net
  • 気象データ取得: Open-Meteo
  • 周辺施設情報: OpenStreetMap 等を元にしたデータ
  • アプリ内課金・購読管理: Apple App Store、Google Play、RevenueCat
  • 利用状況の分析: Firebase Analytics（Google）
  • 不具合（クラッシュ）の検知と解析: Firebase Crashlytics（Google）
  • 広告配信: Google AdMob
  • アカウント連携・データ同期・釣果写真のバックアップ・匿名の釣果統計: Firebase Authentication / Cloud Firestore / Cloud Storage / Cloud Functions（Google）
  • アカウントへのログイン: Apple（Sign in with Apple）、Google（Google アカウントでのログイン）
  • 不正利用の防止: Firebase App Check（Apple App Attest / Google Play Integrity）

これらの外部サービスには、機能提供に必要な範囲で地点情報、購読状態、匿名識別子などが送信される場合があります。 クレジットカード番号などの決済情報は、本アプリでは直接取得・保存しません。

4. 利用目的

  • 釣れやすさ、潮汐、天気、風、周辺施設を表示するため
  • 釣行記録、魚図鑑、お気に入り地点、プロフィールを管理するため
  • プレミアム機能の購入状態を確認し、機能制限を切り替えるため
  • 匿名の釣果統計を集計し、釣り場ごとによく釣れている魚と時間帯を表示するため
  • 行った人のうち釣れた割合など、釣れやすさの目安を作るため
  • 無料ユーザーへの広告配信、広告効果の測定、不正利用の防止のため
  • アプリの不具合調査、品質改善、利用体験の向上のため

5. 第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの個人情報を第三者に販売することはありません。 ただし、上記の外部サービスを通じて、機能提供に必要な情報が各サービスに送信される場合があります。

6. 広告について

無料でご利用いただく場合、アプリ内に Google AdMob の広告を表示します。 プレミアムをご利用いただいている期間中は、広告を表示しません。

  • 広告の配信、効果測定、不正利用の防止のために、IPアドレスから推定されるおおまかな地域、端末情報、広告識別子、広告の表示・操作情報、診断情報などが Google および広告配信パートナーに送信される場合があります。
  • iOS では、端末の追跡許可画面で「許可」を選んだ場合に限り、他社のアプリやWebサイトを横断する広告識別子（IDFA）を利用します。許可しない場合も、魚スイッチの機能はすべてご利用いただけます。
  • Android では、端末のプライバシー設定から広告 ID を削除またはリセットできます。
  • 法令上必要な地域では、アプリ内の「広告のプライバシー設定」から同意内容を確認・変更できます。

Google によるデータの取り扱いについては Google のポリシーと規約 をご確認ください。

7. 通知について

ユーザーが通知を許可した場合、釣れやすい時間の前などに通知を送ることがあります。 通知は端末の設定からいつでも無効にできます。

見守り機能で共有を実行すると、ユーザーが選択した端末の共有先アプリへ、地点名と帰宅予定時刻を含むメッセージが渡されます。 共有先や送信相手、送信内容を本アプリの運営者が取得・管理することはありません。 この機能は第三者への自動通知や安否確認を行うものではありません。

8. データの削除

端末内に保存されたデータは、アプリ内の削除・復元操作、またはアプリのアンインストールにより削除できます。 購読・購入履歴は App Store、Google Play、RevenueCat の管理対象となるため、各サービスの管理画面をご確認ください。

匿名の釣果統計として送信済みの情報は、他のユーザーの記録と合算した件数として保存されるため、個別に取り出して削除することはできません。

9. 未成年の利用

未成年の方が本アプリを利用する場合は、保護者の同意を得たうえでご利用ください。

10. 変更について

本ポリシーは、必要に応じて変更されることがあります。重要な変更がある場合は、アプリ内または本ページでお知らせします。

11. お問い合わせ

本ポリシーに関するお問い合わせは、App Store または Google Play に掲載されているサポート連絡先までお願いいたします。
